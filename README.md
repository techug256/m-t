# M&T Tours & Travel — GitHub Pages 

A static redesign sample for M&T Tours & Travel.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive design
- `script.js` — mobile menu + demo WhatsApp inquiry form

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload these three files.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save. GitHub will provide the Pages URL.

## Notes
- The sample uses remote Unsplash images for demonstration. Replace them with M&T's own licensed photography before production.
- The inquiry form is intentionally simple and opens WhatsApp rather than storing customer data.
- Prices/content are based on the current public M&T Tours sample site and should be verified before launch.
